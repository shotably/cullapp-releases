# CullApp downloads

Installers for **[CullApp](https://getcullapp.com)**, the fast RAW photo culling app for Mac and Windows.

Get the latest version from **[Releases](https://github.com/shotably/cullapp-releases/releases/latest)**, or at **[getcullapp.com](https://getcullapp.com/#download)**.

- `CullApp-x.y.z-arm64.dmg`: Mac with Apple Silicon (M1 and later)
- `CullApp-x.y.z-x64.dmg`: Intel Mac
- `CullApp-Setup-x.y.z.exe`: Windows 10 and 11

Every download includes a free 14-day trial. Support: support@getcullapp.com
